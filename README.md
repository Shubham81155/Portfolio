## Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Shubham81155/Portfolio.git
```

2. Open the project folder:

```bash
cd Portfolio
```

3. Open `index.html` in your browser. No build step is required.

## Updating Content

- Edit text, projects, and skills in `index.html`.
- Replace `Shubham_Pandey.pdf` to update the resume; the site links to it by file name.
- Push to `main` and Vercel redeploys automatically.
